1The price gap is real. The accuracy gap is not.

Across all 2,000 prompts the frontier tier costs a mean 62.6x more per turn, yet buys a mean accuracy advantage of only +0.018 on a 0–1 correctness scale. The distribution is starker than the mean: the cheapest model was already perfect on 70% of prompts, the two tiers tied on 84%, and the frontier model lost outright on 6.8%.

2The 62x pays off in exactly one place: the code-writing role.

Mapping each benchmark prompt onto the Avaloka agent role it belongs to, the frontier gain over the cheap gpt-4o-mini is concentrated almost entirely on the profiler and coder. On the planner — the largest prompt in the system and the most expensive agent to upgrade — it is zero. This independently reproduces Avaloka's own model-routing-cost guidance.

3The biggest routing decision is “no fallback needed”.

Grouping by fallback policy shows the largest segment is the literal category None — 1,631 rows, 81.6% — where the cheap model already sufficed. Avaloka preserves it as a real category rather than collapsing it into a missing-value group (audit Finding 5).

4A router is learnable from pre-call features alone.

Using only what is known before a call runs — prompt structure, domain, role, reference length — Avaloka trained and validated a router for high_compute_route. It beats the trivial baseline on the confidence interval and is certified deployable.

5Engineering audit: what held, and what didn't.

Reproducible with python scripts/03_reproduce_edge_cases.py. Four of four contract checks hold; one declared gap reproduced; two further problems found by hand. Full detail, root causes and suggested fixes in audit/ENGINEERING_AUDIT.md.

Two root causes, one run. The workbook reader chose a sheet by non-empty cell count, ignoring the question (avaloka/io/loader.py::_read_excel, line 158) — the declared defect. And the sizing line spoke “99 rows” for a sheet with 400, because avaloka/workload.py::peek (lines 84–85) treats every non-Parquet suffix as CSV and counts newline bytes inside the xlsx ZIP. That second one is undeclared, small, and speaks a confident wrong number first.
The verdict has no word for “I did not answer you.” Ask something the data cannot answer and the bundle returns two verdicts at once. goal_analysis.json reports status: "limited" — “not an answer to the question”. Beside it, validation_report.json reports verdict: pass. The Validator runs eight checks for whether a result is safe, and none for whether the question was answered. Five lines in validator.py would close it — and would also catch the wrong-sheet read above, which currently passes silently too.

6Reproduce it

python scripts/01_fetch_and_prepare_data.py   # data — no key, 0 LLM tokens
python scripts/02_verify_ground_truth.py      # deterministic ground truth
avaloka analyze data/sprout_llm_routing.csv --goal "average frontier_gain_over_mini by agent_role"
avaloka train   data/sprout_pre_execution_routing.csv --target high_compute_route --deployable
avaloka coordinate data/sprout_llm_routing.csv --workers 4
python scripts/03_reproduce_edge_cases.py     # the audit
